# PRD - 나만의 여행 지도 (초안)

> 기준 문서: [IDEA.md](IDEA.md). 이 문서와 IDEA.md가 다르면 IDEA.md를 따른다.
> 범위: v0.1 ~ v1.0

## 1. 목표

우리나라 시·군·구 지도에 내 여행을 기록하고, 다닐수록 지도가 채워지는 것을 보는 개인 여행 앱을 만든다.

- 기록의 단위는 "지역"이 아니라 **"여행(Trip)"** 이다. 한 지역에 여행이 여러 개 쌓일 수 있다
- 같은 지역을 여러 번 가도 "첫 번째 여행", "두 번째 여행"처럼 따로 남는다
- 지도 색칠과 지도 완성도로 다닐수록 지도가 완성되는 재미를 준다
- 기존 여행 앱의 불편함(같은 지역 재방문 기록이 애매함, 마음에 안 드는 UI)을 해결한다
- 기존 앱의 사진 문제(사진이 뭉개짐, 한 장밖에 못 넣음)는 v1.2에서 해결한다
- 학습용 프로젝트다. 화면 → API → DB → 배포 순서로 버전을 나눠 단계적으로 만든다

## 2. 대상 사용자

| 구분 | 내용 |
|---|---|
| 사용자 | 지금은 나 혼자 (로그인 없음). 여러 사람이 쓰는 것은 v2.0부터 |
| 사용 기기 | 아이폰, 안드로이드, 컴퓨터 브라우저 |
| 사용 상황 | 여행을 다녀온 뒤 기록을 남기고, 지금까지 다닌 곳을 지도로 돌아본다 |
| 주의 | v2.0 전에는 배포 주소를 알면 누구나 볼 수 있으므로 연습용 기록만 넣는다 |

## 3. 기능 목록

| ID | 기능 | 설명 | 버전 |
|---|---|---|---|
| F-01 | 전국 지도 보기 | 첫 화면에 전국 시·군·구 경계 지도를 보여 준다. 구가 있는 일반 시(수원시 장안구 등)는 하나의 시로 합치고, 특별시·광역시의 구는 따로 보여 준다 | v0.1 |
| F-02 | 지역 여행 목록 | 지도에서 지역을 누르면 지역 화면으로 이동해 그 지역의 여행 목록을 보여 준다. 목록은 최신순(시작일 기준, 시작일이 같으면 나중에 기록한 여행이 위)이고, 각 여행에 "첫 번째 여행"처럼 번호를 붙인다 | v0.1 |
| F-03 | 여행 추가 | 지역 화면에서 새 여행을 기록한다. 아래 "여행 입력 규칙"을 따른다 | v0.1 |
| F-04 | 여행 상세 | 여행 하나를 눌러 날짜와 여행일기를 본다 | v0.1 |
| F-05 | 여행 수정 | 여행의 날짜, 여행일기, 동네(v0.4부터)를 고친다. 아래 "여행 입력 규칙"을 따른다 | v0.1 |
| F-06 | 여행 삭제 | 여행을 삭제한다. 삭제하기 전에 한 번 더 확인을 받는다 | v0.1 |
| F-07 | 여행 번호 매기기 | 한 지역 안에서 시작일 순서로 번호를 매긴다. 시작일이 같으면 먼저 기록한 여행이 앞 번호다. 날짜를 고치거나 여행을 삭제하면 번호를 자동으로 다시 매긴다 | v0.1 |
| F-08 | 지도 색칠 | 지역별 여행 횟수로 색을 칠한다. 0번 흰색, 1번 연두색, 2번 이상 진한 초록 | v0.1 |
| F-09 | 서버에 기록 저장 | 기록을 브라우저 대신 서버(API)를 통해 저장하고 불러온다. 서버 메모리에 저장하므로 서버를 끄면 사라진다 | v0.2 |
| F-10 | 기록 유지 | 기록을 DB(Neon)에 저장해 서버를 다시 켜도 기록이 남아 있다 | v0.3 |
| F-11 | 동네 선택 | 여행을 추가하거나 수정할 때 그 지역의 동네(읍·면·동)를 여러 개 고른다 | v0.4 |
| F-12 | 지형 무늬 색칠 | 2번 이상 가 본 지역을 진한 초록 대신 위성에서 본 것 같은 지형 무늬로 칠한다 | v0.4 |
| F-13 | 지도 완성도 | 가 본 시·군·구 넓이 ÷ 전체 땅 넓이를 %로 보여 준다. 전체 땅 넓이는 지도 데이터에 있는 모든 시·군·구 넓이의 합이다 (섬 포함) | v0.4 |
| F-14 | 배포 | 인터넷 주소로 접속해서 쓸 수 있게 배포한다 | v1.0 |
| F-15 | 휴대폰 홈 화면 설치 | 휴대폰 홈 화면에 앱처럼 설치해서 연다 | v1.0 |
| F-16 | 지도 확대·이동 | 지도를 확대하고 이동할 수 있다. 휴대폰에서도 작은 지역을 누를 수 있게 한다 | v0.1 |

### 여행 입력 규칙 (F-03, F-05)

| 항목 | 필수 | 규칙 |
|---|---|---|
| 시작일 | 필수 | 오늘까지만 고를 수 있다 (미래 날짜 불가) |
| 종료일 | 선택 | 없으면 당일치기. 시작일보다 빠르면 저장하지 않고 안내 문구를 보여 준다 |
| 여행일기 | 선택 | 최대 2,000자. 2,000자에서 더 입력되지 않게 막고, 남은 글자 수를 보여 준다 |

## 6. 성공 기준

### 공통
- 지도 색칠, 여행 번호, 지도 완성도(v0.4부터)는 계산 함수로 따로 있고, 테스트가 모두 통과한다
- 아이폰, 안드로이드, 컴퓨터 브라우저에서 화면이 깨지지 않고 쓸 수 있다

### 버전별
| 버전 | 성공 기준 |
|---|---|
| v0.1 | 지도에서 지역을 눌러 여행을 추가·수정·삭제할 수 있다. 여행을 눌러 날짜와 여행일기를 볼 수 있다. 같은 지역에 여행이 2개 이상이면 번호가 시작일 순서로 붙고, 목록은 최신순으로 보인다. 여행 횟수에 따라 지도 색이 흰색 → 연두색 → 진한 초록으로 바뀐다. 휴대폰에서 서울의 구처럼 작은 지역도 확대해서 누를 수 있다. 미래 날짜는 시작일로 고를 수 없고, 종료일이 시작일보다 빠르면 저장되지 않는다. 여행일기는 2,000자에서 더 입력되지 않는다. 여행을 삭제하기 전에 확인을 받는다 |
| v0.2 | 새로고침해도 서버가 켜져 있는 동안은 기록이 남아 있다 |
| v0.3 | 서버를 껐다 다시 켜도 기록이 남아 있다 |
| v0.4 | 여행에 동네를 여러 개 고를 수 있다. 2번 이상 간 지역이 지형 무늬로 보인다. 지도 완성도 %가 화면에 보인다 |
| v1.0 | 배포 주소로 휴대폰에서 접속해 기록할 수 있고, 휴대폰 홈 화면에 설치해서 열 수 있다 |
