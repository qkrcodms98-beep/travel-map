# 트레이스 (나만의 여행 지도)

## 한줄 소개
우리나라 지도에 내 여행을 기록하고, 여행 다닐수록 지도가 위성사진처럼 완성되는 나만의 여행 앱
- 앱 이름은 "트레이스"다 (v1.0부터). "나만의 여행 지도"는 첫 화면 부제로 쓴다

## 누가 쓰는가
- 지금은 나 혼자. 로그인 없음
- v2.0부터 주변 사람들도 각자 계정으로 자기 지도를 채운다
- 아이폰, 안드로이드, 컴퓨터 브라우저에서 사용

## 왜 만드는지?
- 기존 앱은 사진이 뭉개진다
- 사진을 한장밖에 못 넣는 경우도 많다
- 같은 지역을 두번 가면 기록이 애매해진다
- 기존 앱의 UI가 마음에 안 든다

## 핵심 아이디어
- 기록의 단위는 "지역"이 아니라 "여행"이다
- 한 지역은 여행을 여러 개 가질 수 있다 (예: 경주 첫 번째 여행, 두 번째 여행)

## 정한 규칙
- 한 여행은 한 지역에만 속한다. "부산 → 경주" 여행은 부산 여행, 경주 여행으로 따로 기록한다
- 구가 있는 시(수원시 장안구 등)는 하나의 시로 합친다. 서울·부산 같은 특별시·광역시의 구는 따로 본다
- 동네는 읍·면·동(행정동 기준)을 말한다. 한 여행에 동네를 여러 개 고를 수 있다 (v0.4부터)
- 여행 번호는 시작일 순서로 매긴다. 날짜를 고치거나 여행을 삭제하면 번호는 자동으로 다시 매겨진다. 시작일이 같으면 먼저 기록한 여행이 앞 번호다
- 여행 목록의 최신순은 시작일 기준이다. 시작일이 같으면 나중에 기록한 여행이 위에 온다
- v2.0(로그인) 전에는 배포 주소를 알면 누구나 기록을 보고, 고치고, 지울 수 있다. 그래서 배포 주소는 다른 사람에게 알려 주지 않고, 여행일기에 너무 개인적인 내용은 쓰지 않는다
- 종료일이 시작일보다 빠르면 저장하지 않고 안내 문구를 보여 준다
- 시작일은 오늘까지만 고를 수 있다 (미래 날짜 불가)
- 여행을 삭제할 때는 한 번 더 확인을 받는다
- 여행일기는 2,000자에서 더 입력되지 않게 막고, 남은 글자 수를 보여 준다

## MVP (꼭 필요한 것)
- 전국 시·군·구 지도 보기
- 지역을 누르면 그 지역의 여행 목록 보기 ("첫 번째 여행"처럼 번호, 최신순)
- 여행 추가: 시작일(필수), 종료일(없으면 당일치기), 여행일기(선택, 최대 2,000자)
- 여행 수정: 날짜, 여행일기, 동네(v0.4부터)
- 여행 삭제
- 지도 색칠: 안 가본 곳 흰색, 1번 연두색, 2번 이상 진한 초록
- 서버를 다시 켜도 기록 유지 (v0.3부터)
- 지도 확대·이동 (휴대폰에서 작은 지역도 누를 수 있게)

## 지금은 빼는 것
- 사진 (v1.2에서 추가)
- 로그인, 공유, 댓글
- 기록을 파일로 내려받기(백업) (v1.0 다음 할 일. 버전은 아직 정하지 않음)
- 다른 나라 지도
- 동행자, 태그, 검색
- 여러 지역을 하나의 여행으로 묶기
- 녹음 (v1.3에서 추가)
- 노래 음원 넣기 (저작권 문제로 하지 않음)
- 지도 채우기 애니메이션 (v1.1에서 추가)
- 지도를 확대하면 시·군·구 이름 보이기 (나중 버전에서 추가. 버전은 아직 정하지 않음)

## 지도 색칠 규칙
- 안 가본 곳: 흰색
- 1번 가본 곳: 연두색
- 2번 이상 가본 곳: 위성에서 본 것 같은 지형 무늬 (v0.4, 그 전에는 진한 초록)
- 다닐수록 지도가 완성되는 재미 (지도 완성도 %, v0.4)
- 첫 화면 지도에는 시·도 이름(서울, 경기 등)을 늘 보여 준다 (v0.5)
- 지도 완성도 % = 가 본 시·군·구 넓이 ÷ 전체 땅 넓이 (전체 = 지도 데이터의 모든 시·군·구 넓이 합, 섬 포함)

## 화면
1. 전국 지도 (홈)
2. 지역 화면 (여행 목록)
3. 새 여행 기록 (v0.4부터 동네 선택 포함)
4. 여행 상세 (여행 일기)

- v0.4 동네 선택, 지형 무늬, 지도 완성도

- v1.0 배포 + 홈 화면 설치 (화면 Vercel, 백엔드 Render, DB는 Neon 배포 전용 브랜치. 앱 이름 "트레이스")

- v1.2 사진 여러 장 (원본 화질, 사진 저장소 정하기)
- v1.3 그날의 소리 (녹음, 여행 상세를 열면 자동 재생, 끄기 가능, 끈 상태 기억)
